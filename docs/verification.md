# Проверки ImageTwin

Проверено 11 сентября 2026 года на Docker Desktop, ARM64.

| Проверка | Результат |
|---|---|
| PostgreSQL/pgvector и S3 integration tests | **20 passed in 3.73s** |
| Ruff lint / format / uv.lock | Пройдены |
| API, база, очередь, S3 и фоновые процессы | Healthy |
| Seed дважды | Успешно |
| Runtime | pytest, Ruff и scikit-image отсутствуют |
| OpenAPI | Снимок совпадает с API |

Через HTTP проверены четыре преобразования фотографии, точная дедупликация,
отклонение постороннего снимка и удаление из S3 и поиска. При отказе S3 повтор
того же запроса успешно завершил загрузку. SIGKILL worker дал две попытки
с одной зафиксированной индексацией.

Тесты покрывают конкуренцию загрузок, права владельца, ограничения файлов,
повреждение объекта, stale token, откат транзакции признаков и события,
удаление во время обработки и повторную индексацию. На независимой группе
из четырёх снимков комбинация признаков нашла 16 из 16 изменённых копий;
ложных совпадений среди 48 отрицательных пар не было. Набор мал и не является
оценкой качества на произвольном каталоге.

Подробности: [verification.json](verification.json), [evaluation.json](evaluation.json).
Повторение: [runbook.md](runbook.md). GitHub Actions повторяет проверки; [актуальный статус](https://github.com/dasferwer/image-twin/actions).
