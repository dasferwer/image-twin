# Тестовые изображения

Снимки взяты из [открытого набора scikit-image](https://scikit-image.org/docs/stable/api/skimage.data.html),
приведены к RGB и уменьшены до 640 пикселей по длинной стороне. Авторы,
лицензии, ссылки на описание каждого изображения и hashes итоговых PNG
перечислены в [source.json](source.json).

| Изображение | Автор / источник | Условия |
|---|---|---|
| camera | Lav Varshney | CC0 |
| coffee | Rachel Michetti | CC0 |
| chelsea | Stefan van der Walt | CC0 |
| eagle | Dayane Machado | CC0 |
| horse | Andreas Preuss | CC0 |
| human_mitosis | David Root | CC0 |
| microaneurysms | Andreas Maier | CC0 |
| astronaut | NASA | Public domain |

Изменённые копии создаёт `scripts/fixtures.py`: JPEG, уменьшение, обрезка
и водяной знак. Это воспроизводимый тест преобразований. Тематика снимков
разная; набор не представляет реальные фотографии одного маркетплейса.
